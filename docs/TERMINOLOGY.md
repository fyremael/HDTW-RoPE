# Terminology Registry

**Alignment mass:** Nonnegative gradient-derived or hard-path mass over source–target cells. It is normalized explicitly before clock extraction.

**Latent clock:** A monotone scalar or vector coordinate attached independently to each modality token.

**Hierarchical clock:** A vector containing physical, metrical, lyric-local, phrase, section, and occurrence coordinates.

**Rotary transport:** Norm-preserving application of coordinate-dependent 2D rotations to query/key representations.

**Warp:** A monotone deformation between modality-native parameterizations; it need not be globally affine.

**Occurrence identity:** Absolute instance of a repeated structural unit, such as the second chorus.

**Structural identity:** Reusable type of a unit, such as chorus, verse, or bridge.

**Fail closed:** Reject or explicitly mark invalid state rather than fabricate a fallback alignment or coordinate.
